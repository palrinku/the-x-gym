# The X Gym Website

A responsive gym landing page built with plain HTML, CSS and JavaScript.

## Run it
1. Extract `x_gym_website.zip`.
2. Open `index.html` in your browser, or use VS Code Live Server.
3. Edit `style.css` to change colors/layout and `script.js` for interactions.

## Customize before publishing
- Replace the sample phone number and address in `index.html`.
- Update membership prices and trainer details.
- Replace the Unsplash image URLs in `index.html` with your own gym photos when ready. The hero image URL is set in `style.css`.
- Set `recipientEmail` in `script.js` to your Gmail address. The enquiry form opens the visitor's email app with a drafted message; the visitor must press Send.

## Get the site on Google
1. Publish the site on a public web host and connect your domain. A local `index.html` cannot be indexed.
2. Replace the sample contact details and other demo content with accurate business information.
3. Add the domain as a property in Google Search Console and complete Google's ownership verification.
4. Submit the site's sitemap in Search Console (create one for the final public domain) and use URL Inspection to request indexing of the homepage.
5. If this is a local gym, create or claim its Google Business Profile and keep the address, phone, hours, and website consistent.

Google controls indexing and rankings, so these steps improve discoverability but cannot guarantee a specific position or instant listing.
